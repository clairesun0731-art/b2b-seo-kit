# B2B SEO Kit Project Instructions

## Project
B2B SEO Kit is a calm, practical SEO workspace for B2B teams.

Website: https://www.b2bseokit.com/

Tech stack:
- Next.js App Router
- TypeScript
- Tailwind CSS
- Vercel deployment
- No backend unless explicitly requested

## Brand Positioning
B2B SEO Kit helps B2B marketers, founders, consultants, SaaS teams, agencies, manufacturers, and export businesses turn keyword research into SEO audits, content briefs, product page improvements, internal links, AI-search-ready content, and qualified leads.

The product should feel like:
- A calm SEO workspace
- A practical toolkit
- A lightweight operating system for B2B SEO
- A checklist-driven workflow

It should not feel like:
- A generic SaaS landing page
- A complex SEO dashboard
- A flashy AI tool
- A full-service SEO agency
- A broad beginner SEO blog

Brand principles:
1. Clarity over dashboards
2. Workflows over raw data
3. Leads over traffic

## Visual Style
Use:
- bg-[#F8FAFC]
- white rounded cards
- slate text
- restrained blue CTA
- checklist rows
- input/output preview blocks
- workflow steps
- small text labels instead of emojis
- simple comparison tables
- clear section hierarchy

Avoid:
- heavy gradients
- noisy dashboards
- emoji-heavy cards
- generic SaaS visuals

## SEO / GEO Rules
Every important page should include:
- Next.js metadata
- canonical URL
- one H1 only
- Quick Answer near the top
- FAQ section
- FAQ schema JSON-LD
- semantic H2/H3 structure
- natural keyword usage
- internal links only to published pages

Published pages:
- /
- /b2b-seo-kit/
- /b2b-seo-audit/

## Development Rules
Before suggesting deployment:
1. Run npm run build
2. Check git diff
3. Confirm network/proxy is working before git push origin main

Do not add dependencies unless necessary.
Do not introduce a backend unless explicitly requested.
Do not link to unpublished pages.
## B2B Project Experience & Community Pain Points

Future tools and page optimizations should incorporate the founder’s real B2B SEO/CRO project experience and community pain points.

Relevant B2B project experience includes:
- B2B GPS / IoT websites
- B2B SaaS websites
- Energy storage / battery product websites
- Export manufacturing websites
- Local service lead-generation websites
- SEO audits for websites with and without GSC data
- Product page SEO, blog content systems, internal linking, CRO, Google Ads, and GEO / AI search optimization

Tools should not produce generic SEO advice. They should reflect real B2B SEO problems, such as:
- Keyword data does not automatically become an SEO strategy.
- Blog traffic often fails to generate qualified leads.
- Product and solution pages are often too thin to rank or convert.
- B2B websites need better CTA paths, inquiry paths, trust signals, and lead tracking.
- Small teams need repeatable workflows, not complex dashboards.
- Many SEO tools are too complex and do not explain what to do next.
- AI search and GEO require clearer structure, descriptive content, FAQs, comparisons, and entity-rich sections.

Every tool output should be practical and action-oriented. Prefer:
- Priority Focus
- Recommended Checks
- Next Steps
- Page Type Recommendations
- Internal Linking Suggestions
- Conversion Path Suggestions
- AI Search / GEO Readiness Checks

Avoid generic outputs like:
- Improve your SEO
- Write better content
- Build more backlinks
- Optimize metadata

Instead, write specific B2B recommendations, such as:
- Map buying-intent keywords to product and solution pages.
- Link educational blog posts to commercial pages.
- Add FAQ blocks for AI search visibility.
- Add use-case, specs, comparison, and trust sections to product pages.
- Track form submissions by landing page.
- Prioritize pages that can generate qualified leads, not just traffic.
